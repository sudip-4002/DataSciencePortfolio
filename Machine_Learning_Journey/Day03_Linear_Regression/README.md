# Day 03 — Linear Regression

## Overview

This project covers **Simple and Multiple Linear Regression** using Python and Scikit-learn.

The practical implementation uses a **Height-Weight dataset** to understand the relationship between height and weight and build a Linear Regression model.

## Topics Covered

- Linear Regression
- Simple Linear Regression
- Multiple Linear Regression
- Residual Error
- Mean Squared Error (MSE)
- Gradient Descent
- Correlation
- Train/Test Split
- Model Training
- Prediction
- Model Evaluation

## Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
