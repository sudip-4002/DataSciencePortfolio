Day 01 — Machine Learning Foundation

60 Days of Data Science & Machine Learning | Day 01

## Overview

Foundational introduction to Machine Learning — what it is, how it relates to AI, Deep Learning, and Data Science, how it differs from traditional programming, and its three major types.

## Learning Objectives
Define Machine Learning
Explain AI vs ML vs Data Science vs Deep Learning
Contrast traditional programming with ML
Identify real-world ML applications
Understand Supervised, Unsupervised, and Reinforcement Learning
Classify real-world problems by ML type
1. What is Machine Learning?

ML enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every case.

Traditional Programming	Machine Learning
Rules + Data → Output	Data + Output → Model
Programmer defines logic	Algorithm learns relationships
Good for well-defined rules	Good for complex patterns
2. AI vs ML vs DL vs Data Science
Artificial Intelligence
└── Machine Learning
    └── Deep Learning

Data Science is an interdisciplinary field (statistics, programming, ML, visualization, domain knowledge) that overlaps with AI/ML but is not a strict subset.

3. Types of Machine Learning
Type	Data	Goal	Examples
Supervised	Labeled	Prediction	Regression, Classification
Unsupervised	Unlabeled	Pattern discovery	Clustering, PCA
Reinforcement	Environment interaction	Maximize reward	Robotics, Game playing
